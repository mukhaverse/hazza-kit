## كيف تبدأون؟

1. فوق في صفحة المستودع اضغطوا **Use this template** (أو **Fork**)، وسمّوه مثلًا `hazza-portfolio`. كذا يصير عندكم نسخة باسمكم تشتغلون عليها وتنشرونها.
2. أو انسخوه لجهازكم عادي (`git clone`) إذا تبون تشتغلون محليًا بس.
3. ابدأوا بالرسايل الصوتية: `client/voice-notes.md`

## المطلوب

ابنوا لهزّاع بورتفوليو بالإنجليزي، صفحة وحدة، تشتغل على الجوال.

1. **اختاروا من 3 إلى 5 مشاريع** من الـ 11. مو كلها.
2. **أول شاشة** تجاوب: مين هزّاع؟ وش يسوي؟ وين يروح الزائر بعدها؟
3. **كل مشروع** يوضح: المشكلة، دور هزّاع بالضبط، والنتيجة. بأي طريقة من الطرق اللي شفناها.
4. **دليل** لكل مشروع: صورة، رابط، أو كود.
5. **الجوال أول.** جرّبوه على 375px قبل أي شي.
6. **التواصل بضغطة.**
7. **اقرأوا كل الملفات قبل ما تبنون.** مو كل شي أرسله هزّاع ينحط، وبعضه لازم ما ينحط أبدًا.

الـ AI مسموح، وتقدرون تستخدمون أي Skill أو مكوّن جاهز. بس **أنتم اللي تختارون المحتوى**، مو الـ AI.

انتبهوا: هزّاع عميل، والعميل مو دايم على حق. اقرأوا طلباته، وخذوا اللي يخدم هدفه.

| | السؤال |
|---|---|
| الوضوح | أعرف مين هزّاع ووش يسوي خلال 3 ثواني؟ |
| المشاريع | مشاريع قليلة وقوية، وكل واحد موصوف بوضوح؟ |
| الدليل | أقدر أشوف المشروع وهو يشتغل؟ |
| التصميم | مرتب على الجوال، مو بس على الكمبيوتر؟ |
| التواصل | أقدر أتواصل معه بضغطة؟ |

وفيه نقاط إضافية لأي شي ذكي لاحظتوه في الملفات وما حطيناه في القائمة.
